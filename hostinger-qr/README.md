# Nilly Dynamic QR Redirector (Hostinger Self-Hosted)

> **created by Nilly graphics (Sotiris Christos)** — **[https://nillygraphics.com/](https://nillygraphics.com/)**

Ultra-lightweight (~7 KB) PHP + JSON dynamic QR redirector for **Hostinger** (or any PHP 8 hosting):
- **Zero database**, **zero monthly fees**, **never expires**
- **<30ms redirect on iPhone & Android Camera**
- **Editable destinations anytime** without reprinting client menus/packaging + **scan counter**

## Installation on Hostinger (2 minutes)
1. In Hostinger File Manager, create folder `public_html/go/` (so URLs look like `https://nillygraphics.com/go/client-name`).
2. Upload `index.php`, `admin.php`, and `.htaccess` from this folder.
3. Open `https://nillygraphics.com/go/admin.php` and create `config.php` with your hashed password.
4. Create a short slug (e.g., `cafe-alpha` → `https://nillygraphics.com/go/cafe-alpha`), then paste that URL into **Nilly PC Manager & Tools → QR & Barcode Pro** to export print-ready **Vector SVG** or **300-DPI PNG**!
